# Godot Wild Jam

Use this repo for Godot Wild Jam work.

## Contributing

Please use branches and pull-requests :)

This is mostly to keep merge conflicts manageable and changes contained.
We all have merge permissions and there will be no code review process.

Try to keep branches small and isolated to the task you're working on, but obviously
this project is only 9 days, so if there's something you can knock out quick
and you know it won't conflict with someone elses work, go ahead and throw it
in your branch.
